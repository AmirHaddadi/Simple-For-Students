# مستندات کامپوننت‌ها (Components Documentation)

کامپوننت‌های پروژه در پوشه `components/` قرار دارند و برای نگهداری ساده و تمیز طراحی شده‌اند:

---

## ۱. `Header.tsx`
* **نوع کامپوننت:** Client Component (`"use client"`)
* **وظیفه:**
  * نمایش لوگو و نشان تجاری سایت
  * پیوند به صفحات اصلی (خانه، محصولات، قوانین)
  * دکمه‌های ورود و ثبت‌نام با آیکون‌های متناسب
  * قرارگیری دکمه سوییچ تم (`ThemeToggle`)
  * منوی همبرگری واکنش‌گرا برای گوشی‌های موبایل و تبلت

---

## ۲. `Footer.tsx`
* **نوع کامپوننت:** Server Component
* **وظیفه:**
  * معرفی مختصر اهداف پروژه دانشگاهی
  * لینک‌های ناوبری و دسترسی سریع
  * اطلاعات و شناسه آموزشی
  * حقوق معنوی و کپی‌رایت با آیکون‌های فونت‌آوسام

---

## ۳. `ThemeToggle.tsx`
* **نوع کامپوننت:** Client Component (`"use client"`)
* **وظیفه:**
  * جابجایی بین حالت روشن (Light) و تاریک (Dark)
  * خواندن حالت ترجیحی سیستم کاربر (`prefers-color-scheme`) در بارگذاری نخست
  * ذخیره وضعیت انتخاب‌شده در `localStorage` برای مراجعات بعدی
  * نمایش آیکون آفتاب/مهتاب با افکت تعاملی

---

## ۴. `Hero.tsx`
* **نوع کامپوننت:** Server Component
* **وظیفه:**
  * المان تصویری و متنی شاخص صفحه اول
  * نمایش ویژگی‌های آماری و نشان‌های اعتمادسازی
  * دکمه‌های فراخوان به عمل (CTA)

---

## ۵. `ProductCard.tsx`
* **نوع کامپوننت:** Client Component (`"use client"`)
* **وظیفه:**
  * نمایش اطلاعات یک محصول (عنوان، دسته‌بندی، امتیاز، قیمت، برچسب ویژه)
  * دکمه تعاملی خرید با تغییر وضعیت لحظه‌ای به «افزوده شد» با آیکون تیک
  * افکت‌های شناوری (Hover) مینیمال و زیبا
