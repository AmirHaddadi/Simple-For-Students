# مستندات پرامپت تولید تصویر هیرو (Hero Section)

این سند شامل پرامپت دقیق جهت تولید تصویر اختصاصی برای بخش Hero وب‌سایت فروشگاهی ساده‌مارکت است.

## مشخصات فنی

* **موضوع تصویر:** پیشخوان و اکوسیستم تجهیزات دیجیتال مدرن، هدفون، ساعت هوشمند و اکسسوری روی میز مینیمال و تمیز با نورپردازی ملایم استودیویی
* **سبک هنری:** 3D Render / Modern Tech Clean Studio Lighting
* **ابعاد:** 1200x900 پیکسل
* **Aspect Ratio:** 4:3
* **فرمت خروجی:** WebP یا PNG با کیفیت بالا
* **محل استفاده در پروژه:** بخش Hero کامپوننت `components/Hero.tsx`
* **نام فایل پیشنهادی:** `hero-showcase.webp`

## پرامپت تولید (Prompt)

```text
A premium 3D isometric minimalist floating showcase of high-end digital gadgets, including a matte black wireless headphone, sleek smartwatch with glowing edge, and minimalist mechanical keyboard. Clean studio lighting, soft blue and indigo ambient backlighting, smooth subtle gradient background, hyper-detailed, clean modern aesthetic, 8k resolution, elegant tech presentation, photorealistic octane render style.
```
