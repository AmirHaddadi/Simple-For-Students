# ساختار پروژه (Project Structure)

پروژه **ساده‌مارکت (Simple Persian E-Commerce)** بر اساس معماری نوین و استاندارد **Next.js App Router** پیاده‌سازی شده است. این مستند به بررسی ساختار پوشه‌ها و وظیفه هر بخش می‌پردازد.

```text
Simple/
├── app/                      # مسیرها و صفحات اصلی اپلیکیشن (App Router)
│   ├── layout.tsx            # چیدمان سراسری (HTML، فونت، متا، راست‌چین rtl)
│   ├── globals.css           # متغیرهای CSS تم، فونت شبنم و فونت‌آوسام لوکال
│   ├── page.tsx              # صفحه اصلی (Landing & Products)
│   ├── login/
│   │   └── page.tsx          # صفحه ورود کاربر
│   ├── register/
│   │   └── page.tsx          # صفحه ثبت‌نام کاربر
│   └── rules/
│       └── page.tsx          # صفحه قوانین و شرایط استفاده
├── components/               # کامپوننت‌های مستقل و قابل استفاده مجدد
│   ├── Header.tsx            # سربرگ سایت با منو و آیکون‌ها
│   ├── Footer.tsx            # پابرگ سایت با دسترسی سریع و اطلاعات
│   ├── ThemeToggle.tsx       # دکمه تغییر حالت شب و روز با ذخیره در LocalStorage
│   ├── Hero.tsx              # بخش معرفی شاخص صفحه نخست
│   └── ProductCard.tsx       # کارت نمایش محصول استاتیک
├── docs/                     # مستندات کامل پروژه
│   ├── project-structure.md  # ساختار پوشه‌ها و فایل‌ها (همین فایل)
│   ├── setup.md              # راهنمای نصب و راه‌اندازی گام‌به‌گام
│   ├── pages.md              # شرح تفصیلی صفحات
│   ├── components.md         # شرح تفصیلی کامپوننت‌ها
│   ├── theme.md              # سازوکار تم تیره و روشن (Dark/Light)
│   └── image-prompts/        # پرامپت‌های استاندارد هوش مصنوعی برای تولید تصاویر
│       ├── hero.md
│       └── products.md
├── public/                   # دارایی‌های استاتیک در دسترس مستقیم مرورگر
│   └── fonts/
│       └── Shabnam.ttf       # فونت استاندارد فارسی
├── package.json              # وابستگی‌ها و اسکریپت‌های پروژه
├── tsconfig.json             # پیکربندی TypeScript
└── README.md                 # معرفی اجمالی و دستورات اجرای سریع
```

## تفکیک وظایف پوشه‌ها

1. **`app/`**: مدیریت صفحات با استفاده از File-system Routing نسخه جدید Next.js.
2. **`components/`**: اجزای مجزا و ماژولار رابط کاربری که به منظور حفظ اصل خوانایی و سادگی کد از یکدیگر تفکیک شده‌اند.
3. **`public/`**: فایل‌های استاتیک نظیر فونت‌ها و تصاویر.
4. **`docs/`**: مستندسازی دقیق جهت تحویل پروژه کلاسی و دانشگاهی.
