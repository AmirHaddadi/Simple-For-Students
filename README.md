# ساده‌مارکت (Simple Persian E-Commerce)

یک وب‌سایت فروشگاه اینترنتی مدرن، زیبا، سبک و راست‌چین (RTL) به زبان فارسی که با بالاترین استانداردهای رابط کاربری و عملکردی توسعه یافته است.

---

## 🌟 ویژگی‌های کلیدی

* **کاملاً واکنش‌گرا (Responsive):** سازگاری بی‌نقص با انواع دستگاه‌ها (موبایل، تبلت و دسکتاپ)
* **راست‌چین اصولی (RTL):** تایپوگرافی چشم‌نواز با فونت استاندارد فارسی شبنم
* **آیکون‌های لوکال (Font Awesome):** بارگذاری آفلاین و بدون تاخیر با استفاده از آیکون‌های متناسب در تمام اجزا
* **حالت روز و شب (Dark / Light Theme):** تضاد رنگی بهینه و حفظ وضعیت انتخاب در `localStorage`
* **محصولات نمونه با تصاویر بهینه‌شده:** بارگذاری تصاویر با فرمت مدرن WebP و قابلیت شبیه‌سازی افزودن به سبد خرید
* **صفحات کامل:**
  * صفحه نخست و لندینگ معرفی
  * ورود به سیستم (`/login`)
  * ایجاد حساب کاربری (`/register`)
  * قوانین و مقررات شفاف (`/rules`)

---

## 🛠 تکنولوژی‌ها

* **Next.js 16 (App Router)**
* **React 19 & TypeScript**
* **TailwindCSS v4**
* **Font Awesome Free (Local)**
* **فونت فارسی شبنم**

## 🚀 نحوه نصب و راه‌اندازی سریع

### ۱. کلون ریپازیتوری

```bash
git clone https://github.com/AmirHaddadi/Simple-For-Students.git
cd Simple-For-Students
```

### ۲. نصب وابستگی‌ها

```bash
npm install
```

### ۳. اجرای محیط توسعه

```bash
npm run dev
```

دسترسی از طریق آدرس: [http://localhost:3000](http://localhost:3000)

### ۴. ساخت و اجرای نسخه نهایی

```bash
npm run build
npm start
```
